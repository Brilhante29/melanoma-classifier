# Intent

Prove a non-clinical melanoma-versus-rest baseline on the official DermaMNIST v2.1 splits. The repository must verify the committed archive, train only on the training split, select the operating threshold only on validation data and report final metrics only on the untouched test split.

The primary number is test ROC AUC. Sensitivity, specificity, accuracy, positive-class counts and the complete confusion matrix are supporting evidence. No result is a clinical-safety claim.
